# Think Before You Click – Phishing Awareness Resource

## Project purpose
This student project teaches people how to recognise suspicious messages and report them safely.

## Campaign
**Name:** Think Before You Click  
**Slogan:** Pause. Check. Protect.  
**Theme:** Phishing awareness.

## What is included?
- `phishing-awareness-guide.md` – simple warning signs and safety tips.
- `incident-report-template.md` – a blank template for reporting a suspected incident.
- `campaign-message.md` – a short awareness message suitable for a poster or school notice.

## Main safety messages
1. Check the sender carefully.
2. Do not open unexpected links or attachments.
3. Never share passwords or one-time verification codes.
4. Use strong, unique passwords and multi-factor authentication.
5. Report suspicious messages to the official IT/helpdesk contact.

## How to use this resource
Read the guide, share the campaign message, and use the incident-report template only with the authorised IT or security team. Do not add real passwords or private personal information to this repository.
